# Obsidian Sync
Create an Unraid compatible Docker image for backing up Obsidian locally.

## Credit
I didn't really like any of the existing Unraid Community Applications so I started searching for a different solution. I found this site [Self-Host Obsidian Sync in 10 Minutes with Docker](https://www.joshuapack.com/self-host-obsidian-sync-in-10-minutes-with-docker/). And decided to give it a shot. At least as a starting point. I want a more secure version which is available locally. Someday I'll have a Tailscale setup to access my server abroad.
